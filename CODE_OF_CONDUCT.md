# Código de conduta

Contribuições devem respeitar os participantes e privilegiar discussões técnicas, evidências reproduzíveis e colaboração construtiva. Não publique dados pessoais, credenciais ou informações de segurança de terceiros sem autorização.

Comportamentos ofensivos, intimidação ou divulgação indevida de dados não são aceitáveis. Para incidentes de segurança, consulte SECURITY.md e use um canal privado.
